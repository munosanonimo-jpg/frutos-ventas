# Delicias Saludables de Sharito · Control de ventas

Aplicación web progresiva para administrar un catálogo de paquetes de frutos secos, registrar ventas por jornada y revisar el resumen mensual. Los datos se guardan localmente en el navegador; usa **Exportar respaldo** para conservar una copia.

## Cómo abrir

En la carpeta que contiene los archivos, inicia un servidor local con `npx serve .` o abre la carpeta en VS Code y usa la extensión **Live Server**. Luego visita la dirección local que indique el servidor. También puedes abrir `index.html` directamente para usar la aplicación, aunque la instalación y el modo sin conexión necesitan servirla por HTTP/HTTPS.

## Instalar en Android

Publica la carpeta en un sitio con HTTPS o ejecútala en la misma red desde un servidor local. Abre esa dirección en Chrome para Android, toca el menú ⋮ y elige **Instalar aplicación** o **Agregar a pantalla principal**. Después de la primera carga, la aplicación queda disponible sin conexión.
